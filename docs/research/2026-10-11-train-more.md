## Interpretation and limits

Train more means collect more chart judgments, inspect disagreements, and improve a separately versioned detector when a behavioral requirement is defensible. The button does not retrain an ML model, change allocation rules, execute orders or launch a perpetual agent runner.

The existing human saw five-year context, but original predictions use 180 sessions. An unmatched observation can reflect context or policy disagreement, not a code defect. The first comparison must expose that distinction and retain uncertain/invalid observations as unscored. It must not silently recompute predictions from longer data and call them the frozen baseline.

The retained ten-year source cache supports additional calibration sampling subject to coverage and target-reuse checks. Training can reuse previously seen broader history, with exposure recorded; it is not unseen validation. Provider prices are retrospective and adjustment/calendar completeness remain unverified. Newly generated five-year training views reject reported splits across their full view until an adjustment policy is verified. Existing split-marked views remain preserved.

All previously displayed issuers, contexts and identity reveals count as exposure. A later candidate requires a separately reserved, newly sourced validation set before any generalization claim. Existing private caches cannot be relabeled as unseen. If fresh validation data are absent, report needs_data and retain the research baseline. No subscription or network acquisition is required to deliver the calibration workflow.

## Decisions proposed

Fewer admitted charts are allowed and the reason is shown; no fabricated positives or shortened five-year views. Persist frozen 180-session predictions before displaying any new round, while the overview supplies five calendar years ending at the same cutoff. Preserve target offsets -19..0.

Separate diagnostics, training-round state, source catalog, exposure ledger, candidate manifests and report snapshots belong under ignored private/training. Default chart research uses reviewed operating-common sources; excluded-instrument controls require an explicit research-only flag and never clear investment eligibility. A vendor EQUITY type alone is not a reviewed classification.

Public research contains protocol and structural findings only. User labels, company-to-case mappings, event differences and report scores remain private. Exposure bootstrap must distinguish historical/exposed releases from active fresh-validation reservations without changing old roles. Missing legacy identity/interval provenance blocks admission. The completed-pass reveal receipt binds its recorded canonical payload/queue fingerprint; it is separate from the detector prediction release. A newly measured journal prefix cannot be presented as a previously recorded chronology commitment.
