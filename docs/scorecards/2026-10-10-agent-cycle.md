# First-cycle scorecard

Primary outcome: a reproducible, honestly bounded free-data and pattern-feasibility verdict, plus a demonstrated TDD agent cycle if the reviewed plan is approved.

| Gate | Acceptance evidence |
| --- | --- |
| Data coverage | Named sample, denominator per field, fetch timestamp, source URLs, actual successes/failures, and normalized-quarter limitations recorded. |
| Classification | Known excluded controls remain excluded/unknown; an `EQUITY` label alone cannot pass them. |
| Fundamental timing | Latest comparable reported quarter versus same prior-year quarter; unavailable/future data visibly blocked. |
| Headquarters | Direct evidence distinguished from SG&A proxy; missing evidence not silently treated as proof of absence. |
| Pattern geometry | Explicit rules for three shapes, completion events and causal pivot delays; completed/uncompleted/negative fixtures. |
| Pattern validity | Separate synthetic recognition, real labeled recognition, and trading-efficacy statuses. No unmeasured accuracy claims. |
| TDD | Red and green outputs captured for each vertical behavior; tests exercise only the three approved seams. |
| Portfolio | $200K starting cash, $8K/100-share sizing, 25-position/cash limits, WAPP stops, four-losers and successive thresholds, repeat-run safety. |
| Entry integration | Missing/stale/unknown evidence or headquarters clearance never generates a buy; completed signal and dated trailing-12-month volatility are required, with lowest-volatility candidate priority. |
| Missing-price recovery | Required exit failure leaves all state unchanged, does not consume a threshold/date, blocks entries, and permits same-date retry when prices arrive. |
| Deployment | Local-only preview reachable and exact startup/reset commands documented. |
| Independent QA | Agent other than implementer reports attempted scenarios, results, and fixes/rechecks. |
| Persistence | Research/plan/briefs and any implementation committed and remote SHA verified; ignored raw/state files excluded. |

Scope: paper execution and personal research only. This cycle does not validate investability, full-exchange coverage, future returns, or an externally distributed market-data service.

Regression risks: adjusted-versus-raw fill prices, corporate actions, quarter/YTD confusion, centered-window lookahead, false chart patterns, loss threshold repeats, unauthorized real execution, and sample coverage overstatement.
