# Cycle 2 scorecard

Primary outcome: a usable local workflow for independently reviewing frozen detector hypotheses and missed patterns, with honest data evidence and protected evaluation inputs.

| Gate | Required evidence |
| --- | --- |
| Reproducibility | Same source hashes/config/seed → same card IDs and split; rebuild refuses to overwrite a different active queue |
| Blinding | Fixed views with no symbol, stratum, predictions, future bars or holdout entries in review HTTP responses; labels/progress cannot act as a score oracle or expose another reviewer answer |
| Sampling | Random and enriched counts separate; split/embargo frozen before labels; no manual cherry-picking |
| Label integrity | Confirmed seams reject invalid IDs/dates/kinds, preserve reviewer provenance and require explicit conflicting revision |
| Score integrity | Pending/uncertain/disagreements never become negatives; strata separate; no holdout metric |
| Source audit | Primary citations for SPAC/HQ/SG&A controls; access failures distinct from missing facts; no new clearance claim |
| TDD | Observed failure/pass per implemented behavior, public-interface tests and independent QA corrections |
| Local workflow | HTTP save/reload/retry, browser labeling and portfolio-state isolation |
| Persistence | Full checks pass, report committed, remote HEAD equality verified |

Agent-authored labels establish only a pilot workflow. An unlabeled sample or small convenience sample cannot establish precision, recall, Sharpe or profitable trading.
