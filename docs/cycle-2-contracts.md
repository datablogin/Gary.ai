# Cycle 2 review interfaces

Public test seams approved by the user on 2026-10-10: “Approve all three review interfaces.” The three existing strategy seams remain approved. This cycle adds a local research workflow; labels cannot alter coverage, detector rules or portfolio state.

1. `build_review_queue(series, config) -> queue`: deterministically select clipped daily-chart windows from cached inputs, freeze source hashes and detector version, and keep anonymous reviewer cards separate from private ticker/prediction/sampling metadata. Include seeded random windows and detection-enriched windows; assign a fixed calibration/holdout split before labels.
2. `record_review_label(queue, labels, entry) -> labels`: accept a reviewer identity, chart ID, completed-pattern kind (or none/uncertain), completion date and short rationale. Reject unknown IDs, invalid/future dates and locked holdout labels. Preserve reviewer provenance; repeated identical submissions are idempotent and conflicting replacements require explicit revision.
3. `summarize_review(queue, labels) -> report`: report calibration labeling coverage and disagreement separately from recognition agreement. Never score unreviewed or uncertain cards as negatives, mix random and enriched strata into an unqualified accuracy estimate, or expose a holdout score before release. Agent labels are pilot review evidence, not Gary's ground truth or strategy-performance evidence. This complete report is coordinator-private. Reviewer HTTP responses expose only their own labels and labeling progress, never recognition comparisons or other reviewers' answers; otherwise revisions could be used to infer predictions from score changes.

The exact JSON formats and matching policy will be frozen in the cycle plan before tests. Holdout release and detector tuning are later work. The local chart view must hide ticker, prediction, sampling stratum and future bars. Raw provider charts, queue metadata and labels remain Git-ignored under `private/cycle-2/`.
