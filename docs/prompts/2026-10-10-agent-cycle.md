# Agent cycle briefs

Coordinator: use these roles for bounded cycles. Assign disjoint files and wait for research evidence before implementation. All agents read strategy-v1.md and the current plan. No agent may assert a validated metric without a named check and inspected output.

## Research Dot — data

Probe representative securities and excluded controls against primary sources. Record measured field coverage, quarter semantics, timestamps, licensing and no-lookahead limits in data-coverage.md. Propose a normalized snapshot and fail-closed eligibility. Own the research file and ignored raw probes only; no application edits or commits.

## Research — patterns

Research causal daily-bar geometry and source/licensing. Propose explicit completion evidence for inverse head-and-shoulders, cup-and-handle and head-and-shoulders top. Record recognition versus efficacy limits. Own pattern-detection.md only; no application edits or commits.

## Developer — one approved seam

Read the approved contract and TDD skill. Select one observable behavior, write its test, run it and capture its failure, implement the minimum to pass, then run it again. Repeat vertically; do not write a whole imagined suite before implementation. Own only assigned module/test files. Use independent fixture expectations and network mocking only at provider seams. Send exact red/green commands/results to the coordinator. Do not commit or change other agents' files.

## Test/QA — independent

Read the public contracts, strategy and research before inspecting implementation. Execute the suite and local preview. Seek missing/future evidence, no-pattern/uncompleted patterns, causal prefix violations, cash/position limits, stops and loss responses, and duplicate runs. Report blockers with a concrete public-interface reproduction. Do not edit developer files; request a failing regression and recheck the fix.

## Deploy — coordinator

After tests pass, start the local preview, inspect its output and give QA the exact endpoint/command and commit. Keep raw provider data, credentials and paper state ignored. Report readiness by gate rather than declaring unmeasured pattern accuracy. End each bounded cycle with a persisted report and next research question.

## Correction loop

Research uncertainty → one testable slice → observed red → minimal green → local preview → independent QA → failing regression for any defect → green → targeted QA recheck → persisted cycle evidence.
